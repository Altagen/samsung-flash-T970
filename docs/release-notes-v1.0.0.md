Docker & Podman on a Samsung Galaxy Tab S7+ (SM-T970): custom kernel with
container support on stock Android 13, Magisk root, native Docker/Podman,
optional Ubuntu chroot with SSH and an XFCE desktop. Validated in April 2026.

**Start here:** the [README](https://github.com/Altagen/samsung-flash-T970#readme)
and the [step-by-step guide](https://github.com/Altagen/samsung-flash-T970/blob/v1.0.0/docs/guide/00-before-you-start.md).

## Attached files

**A backup mirror, not the primary source.** Each third-party file below is
pinned and downloaded from its **official source** by
`scripts/fetch-downloads.sh`. These copies are only used when an official link
is dead or serves a different file, and the SHA-256 is checked either way
([`SHA256SUMS`](https://github.com/Altagen/samsung-flash-T970/blob/v1.0.0/SHA256SUMS)).
Versions, licenses and source-code links:
[docs/mirror.md](https://github.com/Altagen/samsung-flash-T970/blob/v1.0.0/docs/mirror.md).
